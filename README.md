## 📁 Lab 1 : Routage Statique (IPv4)

### 📌 Objectifs du projet
* Configuration des adresses IP sur les interfaces des routeurs.
* Mise en place de routes statiques pour interconnecter plusieurs réseaux distants.
* Sécurisation des accès aux équipements (Console, VTY, SSH et mots de passe).
